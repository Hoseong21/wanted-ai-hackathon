# 승인 기준 및 한도

구매 금액에 따라 필요한 승인권자가 다르다.

| 금액 구간 | 필요 승인 |
|---|---|
| 50만원 미만 | 자동 승인 (팀 예산 내에서 별도 승인 없이 진행 가능) |
| 50만원 이상 ~ 200만원 미만 | 팀장 승인 필요 |
| 200만원 이상 | 부서장(임원) 승인 필요 + 품의서 별도 제출 |

- 1건당 최대 구매 한도는 500만원이다. 500만원을 초과하는 건은 구매팀과 사전 협의가 필수이며, 일반 구매 프로세스로 진행할 수 없다.
- 승인 없이 진행된 구매 요청은 시스템에서 자동으로 반려된다.
